ESP32 Devices & Modules Documentation¶

Welcome to the documentation for custom ESP32-based smart home devices and firmware modules.

This documentation provides setup guides, hardware specifications, and detailed MQTT API references for integrating devices with Home Assistant and other smart home platforms.

Main Sections¶

  • How-to Guides: Step-by-step instructions for initial setup, Wi-Fi configuration, factory reset, and firmware updates.
  • Devices: Hardware specifications, power requirements, and module listings for all supported hardware models (Audio Player, Button Box).
  • Settings: Device configuration settings (work in progress).
  • Modules: Firmware modular components with detailed MQTT commands, status payloads, and telemetry specifications.

Versioning & URL Access¶

This documentation is deployed to GitHub Pages under a versioned path (.../v1/...). Major MQTT API revisions will introduce newer version paths.
