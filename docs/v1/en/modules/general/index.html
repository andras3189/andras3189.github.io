General Module¶

The General module provides system supervision: it aggregates status and telemetry metrics from all active modules across the device and transmits them over MQTT.

Operating Behavior¶

  • On startup: Automatically publishes initial device status (status) and telemetry (telemetry) payloads to the MQTT broker.
  • Periodically: Continues publishing telemetry updates (telemetry) every 120 seconds.

MQTT Interface¶

Subscriptions (Commands)¶

  • Topic: <topic>/command
Command (Payload) Description
status_update Request an immediate device status publication (status).
telemetry_update Request an immediate telemetry publication (telemetry).
restart Trigger a software reboot of the device.

Publications¶

Status Message¶

  • Topic: <topic>/status

Contains core ESP32 runtime state along with status objects from other active modules.

  • esp.lastResetReason: Cause of the most recent reset/reboot.
    • Possible values:
      • POWERON
      • SOFTWARE
      • PANIC
      • INT_WDT
      • TASK_WDT
      • WDT
      • DEEPSLEEP
      • BROWNOUT
      • SDIO
      • UNKNOWN

Example Payload:

{
    "esp": {
        "lastResetReason": "SOFTWARE"
    }
    // status fields from other modules are nested here
}

Telemetry Message¶

  • Topic: <topic>/telemetry

Periodically published system metrics:

Field Type Description
uptime integer Time elapsed since boot in milliseconds (ms).
freeheap_percent integer Percentage of available heap memory remaining (0–100%).
temp_internal float ESP32 internal chip temperature in Celsius (°C).

Example Payload:

{
    "uptime": 83476,
    "freeheap_percent": 53,
    "temp_internal": 34.6
    // telemetry metrics from other modules are nested here
}

Settings¶

The following parameters can be configured in the web interface for the General module:

  • Device name: Friendly identifier for the device, displayed in the web UI header.
  • Language: Web interface language (supported options: English and Hungarian).
