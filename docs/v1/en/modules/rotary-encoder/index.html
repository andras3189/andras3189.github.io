Rotary Encoder Module¶

The Rotary encoder module handles decoding quadrature signals from incremental rotary encoders (knobs) and transmits rotation steps via MQTT.

Operating Behavior¶

  • Tracking: The driver tracks pulse transitions and accumulates rotational steps.
  • Debounce & Batching: To avoid flooding the Wi-Fi and MQTT network with individual micro-events, rotation is batched: an MQTT message is sent only after knob rotation ceases, reporting the net relative position change.

MQTT Interface¶

Publications¶

  • Topic: <topic>/rotaryencoder_<index>
    • <index>: Encoder index (starting from 0).
  • Payload: Net position change as a signed integer (positive for clockwise, negative for counter-clockwise rotation).
  • Example Payload for 3 clicks counter-clockwise:
    • Topic: <topic>/rotaryencoder_0
    • Payload: -3
  • Example Payload for 5 clicks clockwise:
    • Topic: <topic>/rotaryencoder_1
    • Payload: 5
