MQTT Module¶

The MQTT module manages connection and communication with the central MQTT broker, enabling remote commands, real-time status reporting, and telemetry data transmission.

Operating Behavior & MQTT Interface¶

The module monitors broker connection health and periodically sends telemetry reports detailing connection reliability.

Publications¶

  • Topic: <topic>/telemetry
  • JSON Fields:
    • name: Configured base topic of the device.
    • mqtt_errors: Count of MQTT connection failures and disconnect events.

Example Payload:

{
  "name": "esp32_07",
  "mqtt_errors": 0
}

Settings¶

The following parameters are configurable via the web portal:

  • Active: Enable or disable the MQTT client.

  • Broker: MQTT broker IP address or hostname.

    Important Note on Secure SSL Connections

    When using validated SSL/TLS encryption, the client will not accept a raw IP address during certificate hostname verification, even if that IP is listed under alt_names in your certificate extension (.ext) configuration. A valid hostname is strictly required.

  • Port: MQTT broker port (typically 1883 for unencrypted, 8883 for SSL).
  • SSL flag: Enable encrypted TLS communication.
  • Insecure SSL flag: Skip server certificate verification (use with caution).
  • Base topic: Primary device topic prefix used by modules to publish status and subscribe to commands (e.g. esp32_01).
  • Common base topic: Shared topic prefix for group commands. Specific modules (such as Audio and File storage) subscribe to this prefix in addition to their unique base topic (e.g. esp32).
  • Client ID: Unique identifier for broker connection (e.g. Esp32_Client_01).
  • Username: Broker authentication username (optional).
  • Password: Broker authentication password (optional).
  • Keep Alive: Keep-alive ping interval in seconds (default: 30 seconds).
  • Buffer size: Packet buffer allocation in bytes (default: 512 bytes, recommended: 512–1024 bytes). Increase if using larger payloads or long topic paths.
  • CA Certificate: Custom root certificate authority in PEM format: text -----BEGIN CERTIFICATE----- ... -----END CERTIFICATE-----
