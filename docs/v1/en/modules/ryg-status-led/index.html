RYG Status LED Module¶

The RYG status LED module drives three discrete indicator LEDs (Red, Yellow, Green) to provide instant visual feedback on hardware state and communications (such as on the Button Box front panel).

Status Indicators & Color Codes¶

The LEDs indicate the following hardware and network conditions:

LED Color Event / Condition Description
Red Wi-Fi connection error Illuminates when the device is unable to connect to the configured Wi-Fi network.
Yellow MQTT broker error Illuminates when Wi-Fi is connected, but connection to the MQTT broker has failed or dropped.
Green MQTT message sent Flashes briefly to confirm successful transmission of an MQTT payload (e.g. keypress or encoder rotation).
