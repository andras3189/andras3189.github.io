Factory Reset Module¶

The Factory reset module handles clearing stored configurations and restoring default firmware factory settings.

Operating Behavior & Scope¶

  • What is Cleared: Factory reset wipes all stored settings (Wi-Fi credentials, MQTT parameters, custom configurations) and deletes all user-uploaded files stored in flash memory.
  • What is Preserved: Previously installed firmware updates are preserved (the device remains on its currently installed firmware binary rather than reverting to ancient factory flashing).

Execution Methods¶

Factory reset can be triggered via two paths: 1. Hardware Button: Powering on the device while holding the setup button for >10 seconds. 2. Software Web UI: Using the Factory reset option in the web configuration portal.

For step-by-step procedures, refer to the Factory Reset Guide.

LED Blink Sequence during Hardware Reset¶

During a hardware button reset—while reconnecting power and continuously holding the button—an onboard monochrome indicator LED signals the progress:

  • Flashes once per second for 0.1 seconds.
  • Then flashes 5 times (0.1 seconds ON) every 100 ms.
  • Finally turns solid ON for 1 second. At this point, the factory reset is complete, and the button can be released.

Absence of RGB LED Indication

The addressable RGB LED module will not light up or provide feedback during factory reset, because complex peripheral drivers are not yet initialized during early boot execution.

Reconfiguration¶

After a factory reset completes, the device restarts in AP mode. To configure the device again, follow the Quick Start Guide.
