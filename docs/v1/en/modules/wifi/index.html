WiFi Module¶

The WiFi module manages wireless connectivity on the ESP32, providing both the setup Access Point (AP) mode and client connection to local home Wi-Fi networks (STA mode).

Operating Behavior¶

  • Operating Modes:
    • AP (Access Point) Mode: Broadcasts its own Wi-Fi network (ESP32_AP_...) for initial onboarding and network configuration.
    • STA (Station) Mode: Connects as a wireless client to the configured local Wi-Fi infrastructure.
    • Important Note: AP and STA modes cannot run simultaneously.
  • Activating AP Mode: If connection fails or credentials change, AP mode can be forced during boot using the physical button. See the step-by-step instructions in Quick start step 3.
  • Mesh & Extender Roaming Behavior:
    On multi-AP or mesh networks, the device scans and connects to the strongest signal (BSSID) available at boot, and stays connected to that specific access point until the next reboot.

Settings¶

Configurable parameters in the web portal:

  • SSID: Local Wi-Fi network name.
  • Password: Network WPA2/WPA3 pre-shared key.
