Modules Overview¶

The ESP32 firmware features a modular architecture: every smart device model is composed from a combination of these specialized hardware and software components. Each module manages a focused domain and interacts over a unified MQTT interface.

Available Modules¶

  • General: System supervisor, telemetry aggregation, reset reason monitoring, and software reboot triggers.
  • Audio: Multi-channel (10 sinks) WAV playback from internal flash or remote HTTP streaming with priority handling and prebuffering.
  • File storage: Internal flash memory filesystem management (8MB), remote HTTP upload, file deletion, and directory listing over MQTT.
  • MQTT: Broker connection management, SSL/TLS security, unique and common group subscriptions, and connection error metrics.
  • RGB LED: Addressable Neopixel LED driver with color/brightness controls and automatic offline network status alerts.
  • Settings: Built-in asynchronous HTTP webserver for browser-based module and hardware configuration.
  • SHT40: Sensirion digital temperature and relative humidity measurements with telemetry error tracking.
  • Time: Network NTP synchronization, POSIX timezone support, and Unix timestamp publishing.
  • WiFi: AP setup mode, STA client networking, and boot-time strongest signal mesh connection locking.
  • Button: Momentary pushbutton driver with single-click, double-click, and long-press event detection.
  • Button matrix: Multiplexed keypad driver (e.g. 16-key console) with a dedicated hardware reboot trigger.
  • Rotary encoder: Quadrature knob decoder with batch rotation tracking and relative delta reporting.
  • RYG status LED: Discrete Red, Yellow, and Green visual status indicators for Wi-Fi, MQTT, and telemetry pulses.
  • Factory reset: Complete non-volatile memory wipe, default restoration, and monochrome LED blink pattern progress feedback.
