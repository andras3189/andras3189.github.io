RGB LED Module¶

The RGB LED module controls addressable WS2812B / Neopixel RGB LEDs. It supports individual RGB color control and provides automatic status illumination when network connectivity fails.

Operating Behavior & Offline Indication¶

When network communication is disrupted, the LED automatically switches to predefined alert colors:

  • Red: Wi-Fi connection failure in STA mode (local network unreachable).
  • Yellow: MQTT broker connection failure (connected to Wi-Fi, but broker is disconnected).

The brightness of the offline indicator lights can be adjusted independently via MQTT (o_br), ensuring the LED does not cause glare at night.

MQTT Interface¶

Subscriptions (Commands)¶

1. Set Offline Alert Brightness¶

  • Topic: <topic>/command/rgb/rgbLed/o_br
  • Payload: Brightness integer from 0 to 255.
  • Example Payload: 38

2. Set LED Color¶

  • Topic: <topic>/command/rgb/rgbLed/color/<index>
    • <index>: LED index (starting from 0).
  • Payload: RGB values as comma-separated string: red,green,blue (0 to 255).
  • Example Payload to set color: 21,5,36
  • Example Payload to turn off LED: 0,0,0

Publications¶

  • State updates are published immediately to <topic>/status whenever:
    • The offline brightness (o_br) changes.
    • The LED color (color) changes.
  • Topic: <topic>/status
  • JSON Fields:
    • rgbLed.o_br: Offline alert brightness level (0–255).
    • rgbLed.color: Current active color in RGB format ("r,g,b").

Example Payload:

{
  "rgbLed": {
    "o_br": 38,
    "color": "21,5,36"
  }
}
