Quick Start Guide¶

Essential steps to get your device powered on, connected to your local Wi-Fi network, and operational.

1. Connect to the Configuration Access Point¶

  1. Power on the device.
  2. Using a smartphone or laptop, search for Wi-Fi networks and connect to the access point named ESP32_AP_....
  3. Open a web browser to access the configuration portal (or wait for the captive portal prompt).

2. Configure Wi-Fi Credentials¶

  1. Enter your local Wi-Fi SSID and password.
  2. Click Save.
  3. After saving, the device will automatically reboot and attempt to connect to the configured network.

Static IP Recommendation

It is highly recommended to assign a static IP reservation in your router for the device MAC address to ensure consistent network addressing and reliable home automation integration.

3. Unsuccessful Connection: Forcing AP Mode¶

If the device fails to connect to the Wi-Fi network or credentials change, you can force it back into Access Point (AP) mode:

  1. Unplug the power supply from the device.
  2. Press and hold down the hardware button (on the Button Box, press the button at Row 1, Column 1).
  3. Plug the power supply back in while holding the button.
  4. Wait 2 seconds, then release the button.
  5. The device will start in AP mode (ESP32_AP_...).
