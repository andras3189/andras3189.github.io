Button Box v1¶

The Button Box v1 is an ESP32-based desktop control console with a 16-button matrix, 4 rotary encoders, and a tri-color (Red-Yellow-Green) status indicator LED panel designed for direct home automation control.

Hardware Specification¶

  • Power Input: 5V DC, center positive. Recommended power supply: min. 1A, max. 2A.
  • Buttons: 16 physical momentary pushbuttons (arranged in a 4x4 matrix).
  • Rotary Encoders: 4 incremental rotary encoders.
  • AP Mode / Factory Reset Button: The button at Row 1, Column 1 triggers setup and configuration functions (see Quick start and Factory reset).

Included Modules¶

This device includes the following hardware and software modules:

  • Button matrix (16-button matrix driver)
  • Rotary encoder (4 rotary encoder drivers)
  • RYG status LED (Red / Yellow / Green status LEDs)
  • Time (network time synchronization)
  • WiFi (wireless networking)
  • MQTT (telemetry and command interface)
  • Factory reset (factory restore handling)
  • Settings (configuration management)
  • General (system telemetry and status supervisor)
