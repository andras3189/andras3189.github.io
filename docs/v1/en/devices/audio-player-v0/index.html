Audio Player v0¶

The Audio Player v0 is an ESP32-based network audio player featuring an onboard temperature/humidity sensor and multi-color RGB LED status feedback.

Hardware Specification¶

  • Power Input: 12V DC, center positive. Recommended power supply: 2A.
  • Fuse: 1.35A or 1.5A 5x20mm glass fuse.
  • Buttons: 1 physical button (for AP mode, factory reset, and custom actions).

Included Modules¶

This device includes the following hardware and software modules:

  • SHT40 (temperature & humidity sensor)
  • Button
  • Audio (WAV player with 10 sinks)
  • RGB LED
  • Time (network time synchronization)
  • WiFi (wireless networking)
  • MQTT (telemetry and command interface)
  • Factory reset (factory restore handling)
  • Settings (configuration management)
  • File storage (onboard flash storage)
  • General (system telemetry and status supervisor)
