Supported Devices¶

This section provides technical hardware specifications and lists of integrated modules for all custom ESP32 smart home devices.

Device Models¶

Device Name Power Input Fuse Controls Key Features
Audio player v0 12V DC (2A) 1.35A / 1.5A 1 button 10-sink audio player, SHT40 sensor, RGB LED
Audio player v1 5V DC (2A) 1.35A / 1.5A 1 button 5V audio player, SHT40 sensor, RGB LED
Audio player v1 S 5V DC (2A) 1.35A / 1.5A 1 button 5V audio player, RGB LED (without SHT40)
Button box v1 5V DC (1–2A) – 16 buttons, 4 encoders Control desk with button matrix and RYG status LEDs

For detailed MQTT commands, status payloads, and module parameters, see the Modules section.
