Button Box v1¶

A Button Box v1 egy ESP32-alapú fizikai vezérlőpult 16 gombos mátrixszal, 4 rotary encoderrel és háromszínű (piros-sárga-zöld) státusz LED jelzéssel, amellyel otthoni okoseszközök és automatizálások közvetlenül irányíthatók.

Hardver specifikáció¶

  • Árambemenet: 5V DC, belül pozitív (center positive). Javasolt tápegység: min. 1A, max. 2A.
  • Gombok száma: 16 fizikai nyomógomb (4x4-es mátrix elrendezésben).
  • Rotary encoderek száma: 4 forgójeladó (tekerőgomb).
  • AP mód / Factory reset gomb: Az 1. sor 1. oszlop gombja szolgál a beállítási funkciók aktiválására (lásd: Quick start és Factory reset).

Tartalmazott modulok¶

Az eszköz a következő hardver- és szoftvermodulokat tartalmazza:

  • Gomb mátrix (16 gomb kezelése)
  • Rotary encoder (4 forgójeladó kezelése)
  • RYG status led (Piros / Sárga / Zöld állapotjelző LED-ek)
  • Time (hálózati időszinkronizáció)
  • WiFi (Wi-Fi kapcsolatkezelő)
  • MQTT (állapotközlés és parancsok küldése/fogadása)
  • Factory reset (gyári visszaállítás)
  • Settings (konfigurációkezelés)
  • General (általános telemetria és állapotkezelés)
