Audio Modul¶

Az Audio modul lehetővé teszi hangfájlok és hangfolyamok lejátszását az eszközön (pl. I2S DAC-on vagy erősítőn keresztül).

Főbb Jellemzők¶

  • Támogatott formátum: Jelenleg kizárólag WAV formátum támogatott, szabványos 44 bájtos WAV fejléccel (standard PCM).
  • 10 független lejátszási csatorna (Sink 0–9):
    • Minden sinkhez egyedi hangerő állítható be (0–100 közötti érték).
    • Prioritásos megszakítás: Egy alacsonyabb sorszámú sinken indított lejátszás megszakítja a magasabb sorszámú sinken futó lejátszást (pl. a 0-s sink leállítja az 1-9-es sinkeket).
  • Lejátszási források:
    • Flash tároló: Belső flash memóriából történő lejátszás (a flash mérete korlátozott, tipikusan 8MB; használatához a File storage modul szükséges).
    • Hálózati URL (HTTP stream): Lokális vagy távoli HTTP szerverről történő közvetlen letöltés és lejátszás.
  • Pufferelés és előpuffer (Prebuffer):
    • A lejátszás dedikált puffert használ (általában 4MB PSRAM).
    • A lejátszás csak akkor indul el, ha a puffer elér egy előre meghatározott feltöltöttséget (prebuffer size). Ez URL és belső fájl esetén külön konfigurálható a beállításokban.
  • Időzített indítás: Lehetőség van a lejátszást egy adott jövőbeli időpontban kezdeni (startAt mező). Ez a pillanatnyi idő és legfeljebb now + 15 másodperc közé eshet (epoch millis formátumban).

Fontos figyelmeztetés a hangerő állításáról

A sinkek hangerejének túl gyakori állítása és elmentése nem ajánlott a flash memória véges írási ciklusszáma (elhasználódása) miatt!

MQTT Interfész¶

Feliratkozások (Parancsok)¶

Egyedi és Közös (Common) Topic Támogatás

Az alábbi parancstopicok mind az eszköz egyedi alap topicjára (<topic>/command/...), mind a webes beállításokban megadható közös topicra (<common_topic>/command/...) feliratkoznak. Ez lehetővé teszi több audio lejátszó egyszerre történő csoportos leállítását, megszólaltatását vagy hangerejének vezérlését.

1. Lejátszás leállítása¶

  • Topic: <topic>/command/audio
  • Üzenet formátum: egyszerű string: stop

2. Flash fájl lejátszása¶

  • Topic: <topic>/command/playFile
  • JSON Mezők:
    • path (string, kötelező): A fájl elérési útvonala a flash tárolón (pl. "/doorbell.wav").
    • sink (szám, kötelező): Célsink indexe (0–9).
    • startAt (szám, opcionális): Lejátszás kívánt kezdő időpontja epoch millis formátumban (now és now + 15s között).

Példa azonnali indításra:

{"path": "/doorbell.wav", "sink": 0}

Példa időzített indításra:

{"path": "/doorbell.wav", "sink": 0, "startAt": 1791922925635}

3. URL stream lejátszása¶

  • Topic: <topic>/command/playHost
  • JSON Mezők:
    • url (string, kötelező): A lejátszandó WAV fájl HTTP elérési útvonala a helyi hálózaton vagy interneten.
    • sink (szám, kötelező): Célsink indexe (0–9).
    • startAt (szám, opcionális): Lejátszás indításának időpontja epoch millis formátumban (now és now + 15s között).

Példa azonnali lejátszásra:

{"url": "http://192.168.1.100/doorbell.wav", "sink": 0}

Példa időzített lejátszásra:

{"url": "http://192.168.1.100/doorbell.wav", "sink": 0, "startAt": 1791922925635}

4. Hangerő beállítása¶

  • Topic: <topic>/command/volume/<sink>
    • sink: Célsink indexe (0–9)
  • Üzenet: A kívánt hangerő értéke számmal kifejezve 0 és 100 között.

Publikációk¶

Állapotváltozás (Státusz)¶

  • Topic: <topic>/status

A modul lejátszás közben és állapotváltozásokkor publikálja az aktuális állapotot.

  • audio.volume: 10 elemű tömb a sinkek aktuális hangerejével (0–100).
  • audio.playState: A lejátszó belső állapota:
    • REQUEST_START
    • STARTING
    • PREBUFFER
    • WAITING
    • RUNNING
    • REQUEST_STOP
    • STOPPING
    • STOPPED
    • UNKNOWN
  • audio.downloadState: Az URL letöltés vagy belső fájl beolvasás állapota:
    • REQUEST_START
    • STARTING
    • RUNNING
    • REQUEST_STOP
    • STOPPING
    • STOPPED
    • UNKNOWN
  • audio.bufferUsed: A puffer aktuális foglaltsága bájtban kifejezve (0 – 4MB, eszköztől függően változhat).

Példa üzenet:

{
  "audio": {
    "volume": [5, 5, 18, 5, 5, 3, 5, 5, 5, 1],
    "playState": "RUNNING",
    "downloadState": "STOPPED",
    "bufferUsed": 2715820
  }
}

Telemetria¶

  • Topic: <topic>/telemetry
  • audio_buf_errors: Azon kritikus puffer-olvasási hibák száma, amelyek a lejátszás megszakadásához/leállásához vezettek.

Példa üzenet:

{
  "audio_buf_errors": 0
}

Beállítások¶

Az Audio modul webes felületén konfigurálható indítási pufferméretek:

  • Fájl indító puffer (bájt): A lejátszás ennyi adat beolvasása és pufferelése után indulhat el, ha a belső flash memóriából történik a WAV fájl lejátszása.
    • Javasolt érték: 16 kB (16384 bájt).
  • Hálózati indító puffer (bájt): A lejátszás ennyi adat letöltése és pufferelése után indulhat el, ha HTTP URL-ről történik a lejátszás.
    • Javasolt érték: A helyi Wi-Fi hálózat minőségétől és zajától függően 16–256 kB. Akadozva, recsegve induló hálózati lejátszás esetén érdemes megemelni ezt az értéket.
