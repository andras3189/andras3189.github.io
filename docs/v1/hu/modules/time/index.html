Time Modul¶

A Time modul felelős a pontos rendszeridő fenntartásáért és szinkronizálásáért hálózati NTP (Network Time Protocol) szerverekről. A pontos idő elengedhetetlen az időzített feladatokhoz és a több eszköz közötti szinkronizált audio lejátszáshoz.

MQTT Interfész¶

Publikációk¶

  • Topic: <topic>/status
  • JSON Mezők:
    • system.unixTimestamp: Pillanatnyi Unix epoch időbélyeg másodpercben.
    • system.timeZoneOffset: Időzóna eltolódása az UTC időhöz képest másodpercben (pl. UTC+2 esetén 7200).

Példa üzenet:

{
  "system": {
    "unixTimestamp": 1792009053,
    "timeZoneOffset": 7200
  }
}

Beállítások¶

A Time modul konfigurációja a webes felületen érhető el:

  • NTP szerverek: Legfeljebb 3 NTP szerver adható meg (pl. IP-cím vagy domain név).
    • Javaslat: Erősen ajánlott egy lokális hálózati NTP szervert megadni elsődleges szerverként a minimális hálózati késleltetés érdekében.
  • Időzóna (Timezone): Szabványos POSIX TZ formátumú időzóna karakterlánc (például Közép-európai idő esetén: CET-1CEST,M3.5.0,M10.5.0/3).
  • NTP szinkronizálási időköz (perc): Az időlekérés gyakorisága az NTP szerverektől percben megadva.
    • Alapértelmezett érték: 15 perc.
    • Audio lejátszást végző eszközöknél a pontos szinkronizált indítás miatt a 15 perc a javasolt beállítás.
    • Érzékelőknél, kapcsolóknál vagy egyéb eszközöknél a 180 perc is megfelelő választás.
