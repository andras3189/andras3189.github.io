RGB LED Modul¶

Az RGB LED modul WS2812B / Neopixel címezhető RGB LED-ek vezérlésére szolgál. Lehetővé teszi az egyedi színek beállítását, valamint automatikus állapotjelzést biztosít offline hálózati hibák esetén.

Működés és Offline Jelzések¶

Amikor az eszköz hálózati kommunikációja megszakad, az RGB LED automatikusan hibajelző állapotra vált át az előre definiált színekkel:

  • Piros: Wi-Fi csatlakozási hiba STA módban (nem érhető el a Wi-Fi hálózat).
  • Sárga: MQTT broker kapcsolódási hiba (Wi-Fi van, de az MQTT kapcsolat megszakadt).

Az offline hibajelző fényerőssége külön parancson keresztül korlátozható (o_br), így éjszaka sem vakít.

MQTT Interfész¶

Feliratkozások (Parancsok)¶

1. Offline jelzőfény fényerejének beállítása¶

  • Topic: <topic>/command/rgb/rgbLed/o_br
  • Üzenet: Fényerő értéke 0 és 255 között (egyszerű szöveg vagy szám).
  • Példa üzenet: 38

2. LED színének beállítása¶

  • Topic: <topic>/command/rgb/rgbLed/color/<index>
    • <index>: A LED indexe (0-tól kezdve).
  • Üzenet: RGB komponensek vesszővel elválasztva: piros,zöld,kék (0–255 közötti értékek).
  • Példa üzenet színbeállításra: 21,5,36
  • Példa üzenet LED lekapcsolására: 0,0,0

Publikációk¶

  • A modul azonnal állapotfrissítést publikál a <topic>/status topicra az alábbi esetekben:
    • Az offline fényerő (o_br) megváltozott.
    • A LED színe (color) megváltozott.
  • Topic: <topic>/status
  • JSON Mezők:
    • rgbLed.o_br: Offline fényerő értéke (0–255).
    • rgbLed.color: Aktuális szín RGB formátumban ("r,g,b").

Példa üzenet:

{
  "rgbLed": {
    "o_br": 38,
    "color": "21,5,36"
  }
}
