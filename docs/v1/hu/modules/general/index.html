General Modul¶

A General modul az eszköz központi felügyeletét látja el: státusz- és telemetria-információkat gyűjt az eszközön futó összes többi modultól, és továbbítja azokat MQTT-n keresztül.

Működés¶

  • Induláskor: Automatikusan státusz (status) és telemetria (telemetry) üzenetet küld az MQTT brokernek.
  • Periodikusan: A továbbiakban 120 másodpercenként telemetria (telemetry) információt küld.

MQTT Interfész¶

Feliratkozások (Parancsok)¶

  • Topic: <topic>/command
Parancs (üzenet) Leírás
status_update Azonnali állapotinformáció (status) küldése az eszközről.
telemetry_update Azonnali telemetriai információ (telemetry) küldése az eszközről.
restart Az eszköz szoftveres újraindítása.

Publikálások¶

Státusz üzenet¶

  • Topic: <topic>/status

Az üzenet tartalmazza az ESP32 rendszerállapotát, valamint a többi aktív modul állapotát.

  • esp.lastResetReason: Az előző újraindulás hardveres/szoftveres oka.
    • Lehetséges értékek:
      • POWERON
      • SOFTWARE
      • PANIC
      • INT_WDT
      • TASK_WDT
      • WDT
      • DEEPSLEEP
      • BROWNOUT
      • SDIO
      • UNKNOWN

Példa üzenet:

{
    "esp": {
        "lastResetReason": "SOFTWARE"
    }
    // további modulok status mezői ide ágyazódnak be
}

Telemetria üzenet¶

  • Topic: <topic>/telemetry

Periodikus vagy kérésre küldött telemetriai adatok:

Mező Típus Leírás
uptime egész szám Az eszköz indulása óta eltelt idő ezredmásodpercben (ms).
freeheap_percent egész szám Szabad dinamikus memória (heap) aránya százalékban (0–100%).
temp_internal tizedes szám ESP32 belső chip hőmérséklete Celsius fokban (°C).

Példa üzenet:

{
    "uptime": 83476,
    "freeheap_percent": 53,
    "temp_internal": 34.6
    // további modulok telemetry mezői ide ágyazódnak be
}

Beállítások¶

A General modul webes beállítási felületén az alábbi paraméterek adhatók meg:

  • Eszköz neve: Az eszköz egyedi, azonosításra szolgáló neve, amely a webes felhasználói felületen (UI) megjelenik.
  • Nyelv: A webes felület nyelve (támogatott: angol és magyar).
