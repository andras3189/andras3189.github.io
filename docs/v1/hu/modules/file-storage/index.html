File Storage Modul¶

A File storage modul kezeli az eszköz beépített nem-felejtő SPIFFS/LittleFS flash tárhelyét. Lehetővé teszi fájlok (pl. csengőhangok, értesítési hangok) tárolását, távoli letöltését HTTP szerverről, törlését és listázását MQTT parancsokon keresztül.

Működés¶

  • Tárhely kapacitás: A flash tárhely mérete korlátozott (hardvermodelltől függően jellemzően 8MB).
  • Biztonságos feltöltés: Ha a letöltendő fájl mérete meghaladná a szabad tárhelyet, a modul a letöltést automatikusan megszakítja és a feltöltés nem valósul meg.
  • Közös topic támogatás: A File storage modul az egyedi <topic>/command/fs mellett feliratkozik a beállításokban felkonfigurálható közös alap topicra is (<common_topic>/command/fs), így egyszerre több eszközre is terjeszthetők fájlok egyetlen paranccsal.

MQTT Interfész¶

Feliratkozások (Parancsok)¶

  • Topic: <topic>/command/fs és <common_topic>/command/fs

A parancsok JSON formátumban küldendők.

1. Fájl feltöltése távoli URL-ről¶

  • action: "upload"
  • url: A forrásfájl HTTP URL-je a helyi hálózaton vagy interneten.
  • target: A célfájl útvonala a flash tárolón (pl. "/doorbell.wav").

Példa üzenet:

{
  "action": "upload",
  "url": "http://192.168.1.100/sound.wav",
  "target": "/doorbell.wav"
}

2. Fájl törlése¶

  • action: "delete"
  • target: A törlendő fájl útvonala a flashen.

Példa üzenet:

{
  "action": "delete",
  "target": "/doorbell.wav"
}

3. Fájlok listázása¶

  • action: "list"

Példa üzenet:

{
  "action": "list"
}

Publikációk¶

Önálló állapot topic

A File storage modul állapota nem kerül be a General modul által periodikusan összegyűjtött központi <topic>/status üzenetbe! Az állapot publikációk kizárólag a dedikált <topic>/status/fs topicra érkeznek állapotváltozáskor (pl. feltöltés közben/után), illetve a list parancs hatására.

  • Topic: <topic>/status/fs

JSON Mezők:¶

  • state: A fájlművelet állapota:
    • RUNNING: Egy művelet (pl. letöltés) éppen folyamatban van. Új művelet ilyenkor nem indítható.
    • IDLE: A modul tétlen, készen áll új parancs fogadására.
  • lastAction: Az utoljára indított művelet neve (upload, delete, list).
  • lastResult: A művelet kimenetele:
    • SUCCESS: Sikeres végrehajtás.
    • ERROR: Hiba történt (pl. letöltési hiba, helyhiány).
    • "": Folyamatban lévő (RUNNING) állapot esetén üres karakterlánc.
  • remaining: Hátralévő letöltendő bájtok száma folyamatban lévő műveletnél (0, ha kész).
  • files: A tárolón lévő fájlok listája (név és méret bájtokban).

Példa üzenet feltöltés közben:

{
  "state": "RUNNING",
  "lastAction": "upload",
  "lastResult": "",
  "remaining": 2883800
}

Példa üzenet befejezéskor vagy listázáskor:

{
  "state": "IDLE",
  "lastAction": "upload",
  "lastResult": "SUCCESS",
  "remaining": 0,
  "files": [
    {
      "name": "doorbell.wav",
      "size": 2883800
    }
  ]
}
