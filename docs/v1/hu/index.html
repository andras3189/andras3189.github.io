ESP32 Eszközök és Modulok Dokumentáció¶

Üdvözöljük az egyedi ESP32-alapú okosotthon eszközök és szoftvermodulok dokumentációjában!

Ez a dokumentáció az eszközök üzembe helyezéséhez, használatához, valamint a Home Assistant és egyéb okosotthon rendszerekbe (MQTT interfészen keresztüli) integrálásához nyújt átfogó segítséget.

Főbb témakörök¶

  • How-to Útmutatók: Gyors lépések az üzembe helyezéshez, Wi-Fi konfigurációhoz, gyári visszaállításhoz és firmware frissítéshez.
  • Eszközök: A támogatott hardverek (Audio player, Button box) technikai specifikációja, tápellátási adatai és tartalmazott moduljai.
  • Beállítások: Eszközszintű konfigurációs lehetőségek (folyamatban).
  • Modulok: Az eszközök szoftveres építőelemei és részletes MQTT API specifikációjuk (parancsok, állapotok, telemetria).

Verziózás és integráció¶

A dokumentáció a GitHub Pages felületén keresztül érhető el a mindenkori verziózott URL alatt (.../v1/...). Nagyobb MQTT API változások esetén új verzió jelenik meg.
